## What the team builds

Cross-platform web and mobile apps, full stack and end to end: the web frontend, the mobile app and the backend both of them talk to, built with React and Capacitor and backed by Supabase and Firebase. ClearHire is one example, a [resume builder](/features/resume-builder) and [employment verification](/features/employment-verification) platform that runs as a web PWA and an Android app from a single React + Capacitor codebase.

The same standards run through all of it. Work happens in the browser wherever it can. Product copy states its limits beside its claims. And the only promotion is first-party, cards for the other apps, never a third-party ad network.

## Get in touch

For questions, feedback or collaboration, write through [aoneahsan.com](https://aoneahsan.com) or any of the links above. It reaches the ClearHire team, and a person reads it. The team that reads your bug report is the team that wrote the bug. If ClearHire saves you time, an optional tip at [aoneahsan.com/payment](https://aoneahsan.com/payment?project-id=clearhire&project-identifier=com.aoneahsan.clearhire) supports continued development. It is never required.
