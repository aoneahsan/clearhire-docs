# Moving to ClearHire

This section has one page for each product we compared ClearHire with. Each page gives the steps, a table of what we read on that product’s own pages, and the date we read it. Where nothing can move, the page says so and stops early.

ClearHire has no importer. What you bring across, you type in or paste. The case for each side and the prices are on [ClearHire’s comparison pages](https://clearhire.aoneahsan.com/compare).
